# Node.js Modules and Files — Exercises XP

Run these commands from this directory:

1. `node exercise1/shop.js`
2. `node exercise2/app.js`
3. `node exercise3/app.js` — reads Hello World.txt and replaces Bye World.txt with Writing to the file.
4. `node todoApp/app.js`
5. `cd math-app`, `npm ci`, then `node app.js`.
6. `cd npm-beginner`, `npm ci`, then `node app.js`.
7. `node file-explorer/copy-file.js` and `node file-explorer/read-directory.js`. An optional directory path can be passed to read-directory.js.

Exercises 2 and 4 use ES modules; the others use CommonJS. Chalk 4 is used to support the required `require("chalk")` syntax. To force colors in a non-interactive terminal, run `FORCE_COLOR=1 node npm-beginner/app.js`.
