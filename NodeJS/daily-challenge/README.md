# Daily Challenge: Node.js App & NPM

Install dependencies with `npm ci`.

Run `node app.js` to see the greeting, colorful messages and file contents.
Run `node challenge.js` for the integrated challenge, or `node challenge.js Amit` to supply a name.

The project uses CommonJS modules. Chalk 4 supports the required `require("chalk")` syntax. File paths are resolved relative to the module, so scripts also work when launched from another directory.

If your terminal disables colors, run `FORCE_COLOR=1 node challenge.js`.
