# React Carousel

A single React app using `react-responsive-carousel`, its stylesheet, and Bootstrap. The four supplied images show Hong Kong, Macao, Japan and Las Vegas.

```sh
npm ci
npm run dev
```

Open the local URL shown in the terminal. Use the arrows, indicators, thumbnails, keyboard arrows or swipe to change destinations. Navigation wraps around. Automatic playback is disabled so navigation is controlled by the viewer.

`npm run build` creates the production build; `npm run preview` serves it.

Images are loaded from the assignment's Klook URLs, so an internet connection is required. The package is documented at https://github.com/leandrowd/react-responsive-carousel.
