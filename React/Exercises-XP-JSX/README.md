# React Exercises XP: JSX, Objects and Styling

One React app contains all three exercises. Start with:

```sh
npm ci
npm run dev
```

Open the local URL printed in the terminal. `npm run build` creates a production build; `npm run preview` serves it.

- `src/App.js`: Hello World, the JSX constant, the sum sentence, and Bob Dylan's name.
- `src/UserFavoriteAnimals.js`: class component mapping the animal prop into list items.
- `src/Exercise3.js`: class component with HTML tags, form, link, local image and list. Both Part I's red/lightblue heading and Part II's style_header heading remain visible to demonstrate each step.
- `src/Exercise.css`: the exact requested paragraph style.

The demonstration form prevents page reload. Vite is configured to accept JSX in `.js` files so the assignment's filenames are preserved.
