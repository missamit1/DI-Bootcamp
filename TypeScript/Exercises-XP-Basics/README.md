# TypeScript Exercises XP

All nine solutions are in `exercises.ts`.

With TypeScript installed, run `tsc -p .` in this directory to type-check and regenerate `exercises.js`. Open `index.html` to run the examples in the browser and inspect the Console. Exercise 7 fills the input with `Hello, TypeScript!`.

You can also run `node exercises.js` for the console examples. The DOM exercise only runs in the browser.
